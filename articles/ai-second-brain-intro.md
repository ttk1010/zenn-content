## まず、できあがるもの

「気になったけどよくわからない概念やニュースを放り込むと、**統一されたテイストのイラスト付きで“わかりやすい一枚”にまとまって**Obsidianに貯まっていく」——そんなツール **AI Second Brain** を作りました。個人利用のOSSとして公開しています（[ttk1010/ai-second-brain](https://github.com/ttk1010/ai-second-brain)）。

たとえば `Claude Code` という言葉を1つ入れると、こんな解説イラスト付きのノートが生成されます。文字だけの説明より、全体像がぐっと掴みやすくなります。

## なぜ作ったか

きっかけは、**よくわからない概念を、わかりやすく理解したい**という素朴な悩みでした。文字ばかりの解説記事を読んでも、なかなか頭に入ってこない。最初のうちは検索キーワードに「わかりやすく」と付け足したり、Geminiに噛み砕いてもらったりしていました。

そのうち「**イラストにすれば理解しやすいのでは**」と考え、ChatGPTやGeminiで概念のイラストを生成するようになります。ただ、これが**毎回テイストがバラバラ**で、品質を安定させるのも難しい。「読んで終わり」で成果物も貯まっていきません。

そこで、**同じ視覚言語で・安定した品質のイラスト付きノートを・自動で貯めていく**仕組みを、Claude Codeを使って自分専用に内製化したのがこのプロジェクトです。

## 設計の核：Knowledge Object

AI Second Brainの中心には **Knowledge Object（KO）** という1つのデータ構造があります。入力は必ずまずKOになり、Markdownもイラストもメタデータも**すべて同じKOから生成**されます。

```
入力（概念 / ニュースURL / 比較）
      ↓
 Knowledge Object（要約・背景・関連概念・出典…）
      ↓
Markdownノート ／ イラスト ／ メタデータ ／ 関連リンク
```

「イラストだけ」を入力から直接作らないので、テイストや内容が出力どうしで食い違わず、統一感が保てます。

## 使い方①：3つの知識タイプ

CLIに入力を渡すと、種類を自動判別してノート化します。

```bash
uv run asb "Transformer"                     # 概念
uv run asb "https://ledge.ai/articles/..."   # ニュースURL（取得して要約）
uv run asb --compare "GPT, Claude, Gemini"   # 比較（比較表つき）
```

生成されるノートは、フロントマター＋要約／背景／キーポイント／関連ノート（`[[wikilink]]`）／出典／タグ、という構成。**イラストと合わせて、あとから読み返しても理解しやすい**Markdownとして残ります。「高校生向けに」のような指示を `--guidance` で添えれば、本文もイラストも方向づけできます。

## 使い方②：どこからでも投げ込む

思いついた瞬間に貯められるよう、入口を複数用意しました。

- **Claude Codeのチャット**：いちばん手軽なのがこれ。「〇〇についてナレッジオブジェクトを生成して」と話しかけるだけでノートができます
- **Inboxキュー**：Obsidianの `00 Inbox/` にURLや概念を1行メモ → `uv run asb-inbox` でまとめてノート化
- **Telegram**：Claude Code Channels経由でbotにメッセージを送ると、手元のPCが生成して返信
- **ログイン必須サイト**：ASBが取得できない記事は、ブラウザで開いた本文を渡す方式（認証情報はASBに渡さない）

## 使い方③：月次ダイジェスト

冒頭の2枚目がこれです。`asb-digest` を実行すると、[ledge.ai](https://ledge.ai/) の**30日間アクセスランキングTOP10**を取得し、一文要約つきのダイジェストノートと俯瞰イラスト1枚を生成します。

```bash
uv run asb-digest --top 10
```

目的は「その月の振り返り」だけではありません。むしろ、**しばらく貯めた後に「この時期はどんな話題がホットだったか」を後から振り返る**のが大きな狙いです。毎月1枚ずつ貯めておけば、AIの流れをあとから俯瞰できる“年表”になります。

## 試すには

セットアップは数コマンドです（詳細は[README](https://github.com/ttk1010/ai-second-brain)）。

```bash
uv sync --dev
cp config/settings.example.toml config/settings.toml   # vault_path を設定
echo 'OPENAI_API_KEY=sk-...' > .env
uv run asb "Transformer"
```

保存先のObsidian Vaultはリポジトリ外（自分の好きな場所）。設計判断はADRとして全部リポジトリに公開しているので、**使うだけでなく中身を読む**こともできます。

## コスト感

固定のホスティング費用はゼロで、かかるのは**OpenAIの従量課金だけ**（テキストと画像生成）。同じ入力の再生成はスキップされる冪等設計で、`--no-image` を付ければ画像を省いて節約できます。関連ノートを繋ぎ直す `asb-relink` のような“考える”処理はClaude Code側（サブスク内）で動かし、OpenAI課金をかけない設計にしています。

## まとめ

AI Second Brainは、**わかりにくい概念やニュースを、統一テイストのイラストでわかりやすくまとめて貯めていく**ためのツールです。出力はMarkdownやイラストですが、本体はあくまで積み上がっていく知識そのもの、というのが設計思想です。

このツールは実はほぼ**Claude Codeに“リードエンジニア”をやらせて開発**しました。その**開発手法・爆速開発の実際・AIツールの使い分け**については、別記事で詳しく書く予定です。
